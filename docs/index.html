worldint

Real-time global intelligence, minus the heavy stack.

★ GitHub Get started

Why worldint

⚡ One shared engine

Single async HTTP pool with keepalive + semaphore. A full world brief lands in seconds.

🛡️ Resilient by design

Two-level cache (memory + SQLite) with stale-fallback, plus per-source circuit breakers.

🧠 Instant recall

Built-in local keyword store. No Docker, no GPU, no embedding servers.

🖥️ One CLI, 63 tools

worldint <tool> key=value auto-serves every registered tool.

📡 MCP + dashboard

Stdio MCP server for AI agents and a live SSE ops-center out of the box.

📍 Watch your own area

Circle, polygon & corridor geofences with briefs and enter/leave change detection.

Install

# core: httpx + click + feedparser only
pip install -e git+https://github.com/salim-studio/worldint.git
pip install -e ".[mcp]"        # MCP stdio server
pip install -e ".[dashboard]"  # live dashboard

Usage

worldint tools                          # list all 63 tools
worldint earthquakes min_mag=6 limit=3  # live USGS quakes
worldint macro_signals                  # Fear&Greed + BTC + DXY + gold + 10Y
worldint world_brief                     # cited multi-domain brief
worldint aoi_define name=Cairo lat=30.04 lon=31.23 radius_km=150
worldint aoi_brief name=Cairo           # brief scoped to your area
worldint-mcp                            # MCP server for Claude / Cursor
worldint-dashboard                      # → http://localhost:8501
