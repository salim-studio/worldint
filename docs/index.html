Why worldint

🗺️ Map ops-center

Live Leaflet dashboard: quake markers, signal cards, health panel — plus run any of the 63 tools from the browser.

🔥 Escalation radar

0–100 scores for 22 global hotspots from seismic proximity + headline velocity. Nuclear-test-site seismic watch included.

📈 Market depth

Yield curve + inversion flag, 11-sector heatmap, stablecoin pegs, Nasdaq earnings, composite company profiles.

🚢 Chokepoint watch

Hazard pressure on 9 strategic straits, dry-bulk stress proxy, live FAA delays, real SEC filings & federal awards.

📍 True geofences

Circle, polygon & corridor AOIs with ID-based enter/leave change detection across sweeps.

⚡ Lean & resilient

One HTTP pool, two-level cache with stale-fallback, per-source circuit breakers. Installs in seconds.

Install

# core: httpx + click + feedparser only
pip install -e git+https://github.com/salim-studio/worldint.git
pip install -e ".[mcp]"        # MCP stdio server
pip install -e ".[dashboard]"  # map dashboard

Usage

worldint tools                          # list all 63 tools
worldint hotspot_escalation             # 22 hotspots scored
worldint yield_curve                    # 3M/5Y/10Y/30Y + inversion flag
worldint maritime_watch                 # pressure on 9 chokepoints
worldint nuclear_monitor                # seismic check, 6 test sites
worldint aoi_define name=Cairo lat=30.04 lon=31.23 radius_km=150
worldint aoi_changes name=Cairo         # what entered / left
worldint-mcp                            # MCP server for Claude / Cursor
worldint-dashboard                      # map ops-center → :8501
